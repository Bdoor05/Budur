# ملف الإنجاز المهني الإلكتروني — بدور الشبرمي

موقع شخصي تفاعلي لتوثيق الأداء المهني والإنجازات التعليمية والمبادرات والمشروعات للمعلمة بدور الشبرمي، معلمة رياضيات في ثانوية الموهوبات التقنية بمنطقة حائل.

## طريقة الاستخدام

1. افتح ملف `index.html` في المتصفح.
2. أضيفي الشواهد من قسم **إضافة شاهد جديد**.
3. يمكنك رفع صورة أو ملف PDF مع كل شاهد (حتى 2MB).
4. ستظهر الشواهد تلقائيًا في عناصر الأداء المرتبطة بها.
5. استخدمي **لوحة المتابعة** لمراجعة التوزيع والفجوات.
6. أنشئي التقارير من قسم **التقارير والتصدير**، ثم اطبعيها أو احفظيها PDF.

## التعديل المحمي

تعديل الرؤية والرسالة وصور القيادة وتعديل/حذف الشواهد يتطلب كلمة مرور المسؤولة.

كلمة المرور الافتراضية: `Budur2026`

يمكن تغييرها لاحقًا من داخل الكود أو بربطها بنظام تسجيل دخول حقيقي.

## النشر

الموقع منشور عبر GitHub Pages من الفرع `main`.

## الخصوصية

لا ترفعي بيانات الطالبات أو صورهن أو أسمائهن إلا بعد الحصول على الموافقات المدرسية المناسبة.
