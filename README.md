# ملف الإنجاز المهني الإلكتروني — بدور الشبرمي

موقع شخصي تفاعلي لتوثيق الأداء المهني والإنجازات التعليمية والمبادرات والمشروعات للمعلمة بدور الشبرمي، معلمة رياضيات في ثانوية الموهوبات التقنية بمنطقة حائل.

## طريقة الاستخدام

1. افتح ملف `index.html` في المتصفح.
2. أضيفي الشواهد من قسم **إضافة شاهد جديد**.
3. ستظهر الشواهد تلقائيًا في عناصر الأداء المرتبطة بها.
4. استخدمي **لوحة المتابعة** لمراجعة التوزيع والفجوات.
5. أنشئي التقارير من قسم **التقارير والتصدير**، ثم اطبعيها أو احفظيها PDF.

## النشر

الموقع جاهز للنشر من الفرع `main` عبر GitHub Pages.

## ملاحظة

البيانات تُحفظ محليًا في متصفح الجهاز المستخدم. لتفعيل الحفظ السحابي والمشاركة بين الأجهزة، يلزم ربط الموقع بقاعدة بيانات وتخزين ملفات سحابي.

## الخصوصية

لا ترفعي بيانات الطالبات أو صورهن أو أسمائهن إلا بعد الحصول على الموافقات المدرسية المناسبة.
